# 🎮 My Game Catalog Website

A personal website to catalogue and showcase all the games I've developed or am currently working on.

## 🛠 Tech Stack

- ⚛️ React (with TypeScript)
- 📦 npm
- 💅 CSS Modules
- ⚡️ Vite

## 📋 Current Status

- Basic UI to list games with titles, descriptions, and screenshots
- Individual pages for each game, including diary-style entries for some games
- Home page with a carousel showcasing all games (functionality still in progress)
- Includes some secret features (some are still being developed and aren’t fully functional yet)
- About Me page included

## 🚧 Future Plans

- Improve styling, animations, and mobile responsiveness
- Complete carousel functionality on the home page
- Add test coverage
- Format for mobile devices and different screen sizes
